# Zapret GUI 0.9.12

## Добавлено
- Встроенный hosts с настройкой адреса GeoHide для ChatGPT/OpenAI и сохранением выбранного адреса при обновлении hosts V3nilla.
- Поиск IP-адресов в свежих issues и ответах V3nilla для всех сервисов с публичными IPv4-перенаправлениями в hosts. Записи 0.0.0.0 не изменяются.
- Отключаемая проверка и исправление адресов в hosts при запуске GUI. По умолчанию выключена.
- Журнал проверок с кодами ответа и ссылками на обсуждения.
- Обновление общего списка доменов из V3nilla и импорт локального списка.
- Добавление доменов ChatGPT и Meta / Quest в пользовательский список без удаления существующих записей.
- Кнопки перехода на официальные страницы Meta Quest Developer Hub и Quest Link.
- Кнопка «Файлы Zapret» и открытие папок списков, bin, hosts и настроек GUI.

## Изменено
- Добавлены резервные копии и восстановление списков, а также точечное исправление записей ChatGPT в hosts.
- При обновлении списков проверяется формат, удаляются дубликаты и обрабатывается точка в конце домена.
- Автопоиск не заменяет адрес только на основании ответа в issues: новый адрес должен дважды пройти HTTPS-проверку для конкретного домена.
- Неоднозначные ответы, включая Cloudflare 403/429, не запускают автоматическую замену текущего адреса.

- За проход проверяется до 25 доменов; следующий проход продолжает обход. Локальные, служебные, IPv6 и конфликтующие записи пропускаются.

## Перед установкой
Сохраните копию рабочей папки Zapret и hosts. После изменения списков перезапустите Zapret.

Сборка предварительная: проверены синтаксис исходников и целостность установщика.
Компиляция, установка и новые сетевые функции на Windows ещё не проверены.
Доступность сторонних адресов и всех сервисов Meta не гарантируется.
