# Zapret GUI 0.9.12

Оболочка Windows для поставляемого вместе с ней Zapret: выбор стратегии, управление запуском, автозапуск службы, обновление списков и настройка оформления.

**Отдельно устанавливать Zapret не нужно:** движок включён в установщик. Оболочка компилируется установщиком на компьютере Windows с помощью компилятора .NET Framework.

## Автопроверка всех перенаправлений hosts

Кнопка «Проверить hosts и найти замены в issues» проверяет активные записи всех
сервисов с публичным IPv4, а не только ChatGPT. Записи 0.0.0.0 сохраняются без изменений.
Локальные, частные, служебные IP, IPv6, закомментированные строки и домены с несколькими
разными адресами исключаются. Домен, указанный одновременно с публичным IP и 0.0.0.0,
тоже исключается. В строках с несколькими доменами заменяются только проверенные домены.

За запуск проверяется до 25 доменов, около 3 минут плюс время завершения текущих
запросов. Позиция сохраняется: следующий запуск кнопки или GUI продолжает обход.
Переключатель автопроверки запускает один проход при старте GUI; по умолчанию выключен.
Постоянного фонового опроса нет. Журнал доступен кнопкой и в
`%LOCALAPPDATA%\ZapretSimpleGui\issue-repair.log`.

Для каждого домена текущий IP проверяется по HTTPS. Только после двух транспортных
сбоев или HTTP 5xx выполняется поиск замены. Ответы HTTP 2xx–4xx, включая 403/429,
не запускают замену: это не доказательство, что IP перестал работать.
Поиск читает 30 свежих issues V3nilla и до 100 комментариев максимум 6 подходящих
обсуждений за проход. Обсуждения сопоставляются с доменом, названием из его адреса
или старым IP. Это ограниченный поиск, не полный архив GitHub.

Найденный адрес — только кандидат. Он должен дважды вернуть HTTP 2xx–3xx по HTTPS
для конкретного домена с включённой проверкой сертификата. Не прошедшие проверку
домены сохраняют прежний адрес. Команды из комментариев не исполняются. Используется
системный curl.exe без пользовательского конфига, браузерных cookies и прокси.
Redirect не выполняется. Успех проверки не доказывает работу входа или загрузок.

Перед записью создаётся копия hosts и проверяется, что файл не изменён другой
программой. Откат выполняется кнопкой восстановления hosts. Разным сервисам могут
назначаться разные адреса; общий адрес GeoHide в настройках не изменяется.
Полная замена hosts встроенным или скачанным файлом может перезаписать точечные
исправления, найденные автопроверкой. Перед такой заменой сохраните рабочую копию.

## Meta / Quest на ПК

Кнопка добавляет meta.com, metacdn.com, facebook.com, facebook.net, fbcdn.net,
oculus.com и oculuscdn.com в пользовательский список без удаления его содержимого.
После этого перезапустите Zapret. Есть ссылки на официальные страницы Developer Hub
и настройки Quest/Link. Это начальный набор доменов, не гарантия работы всех сервисов.
Записи Meta в hosts участвуют в общей автопроверке; RIPEstat не подключён.
Проверка фактического входа и загрузок Meta на сети пользователя пока не выполнена.

## Установка и обновление

1. Перед обновлением скопируйте текущую папку Zapret в безопасное место, особенно `lists`, свои стратегии и настройки. Установщик содержит штатные файлы и может заменить их при установке поверх старой версии.
2. Остановите Zapret в приложении и полностью закройте оболочку, включая значок в трее.
3. Запустите `ZapretGui-Setup-0.9.12.exe` в прежнюю папку установки. Для установки и изменения системного hosts нужны права администратора.
4. Откройте приложение и проверьте, что в нём указана версия **0.9.12**. Выберите свою рабочую стратегию, например ALT 11, и запустите Zapret.
5. Если раньше использовались собственные списки, верните их из сохранённой копии. Затем в настройках нажмите «Добавить домены ChatGPT в пользовательский список» и перезапустите Zapret.

Windows x64; необходим установленный .NET Framework с компилятором `csc.exe`. Поставляется также `source/build.cmd` для ручной сборки оболочки. Если установка завершилась ошибкой компиляции, сохраните её полный текст.

## ChatGPT и hosts

В разделе «Списки и обновления» доступны:

| Действие | Результат |
| --- | --- |
| Применить hosts · версия GUI | Полностью заменяет hosts встроенным снимком с выбранным адресом OpenAI; создаёт резервную копию |
| Обновить hosts · V3nilla + настройки GUI | Загружает hosts V3nilla и применяет к записям OpenAI сохранённый адрес |
| Исправить только ChatGPT в текущем hosts | Меняет записи OpenAI и сохраняет остальные записи текущего файла |
| Скачать hosts GUI для ручной замены | Сохраняет встроенный файл и открывает папки для ручной установки |
| Восстановить hosts из резервной копии | Возвращает выбранную копию |

Адрес по умолчанию — **193.233.112.88**. Это сторонний сервер GeoHide, а не заявленный официальный IP OpenAI. Его работоспособность автор проекта подтвердил 14 октября 2026 года. Адрес можно изменить в настройках. При импорте произвольного локального hosts применяется содержимое выбранного файла без автоматической подмены адресов.

Установка приложения сама по себе не заменяет системный hosts. Если текущий доступ уже работает, заменять его повторно необязательно. Для точечного исправления используйте кнопку «Исправить только ChatGPT в текущем hosts».

Если запись заблокирована, программа сохраняет подготовленный hosts для ручной замены, когда это возможно, и показывает инструкции. Она не снимает системные блокировки принудительно. Причина отказа может быть связана с защитой, правами или другим процессом; один отказ записи не доказывает вмешательство антивируса.

## Списки доменов

«Обновить список доменов · V3nilla» загружает файл **«Список доменов для обхода/Сам список.txt»** и заменяет `lists/list-general.txt` с резервной копией. `list-general-user.txt` эта операция не заменяет.

Полный список большой: снимок, полученный 14 октября, содержит 499 227 уникальных нормализованных записей. Он может увеличить расход памяти и нагрузку. Обновление выполняется по кнопке, а не автоматически по расписанию. При проблемах верните резервную копию.

Четыре корневых домена ChatGPT включены в штатный общий список установщика. Для своей существующей конфигурации можно отдельно нажать «Добавить домены ChatGPT в пользовательский список». Чтобы применить изменения списков, остановите и снова запустите Zapret.

Копии списков сохраняются рядом с исходными файлами с суффиксом `.zapretgui.<дата-время>-<идентификатор>.bak` (точный формат имени виден в журнале). Кнопки восстановления позволяют выбрать нужную копию. Восстановление также сохраняет предыдущую версию.

## Локальные файлы

Кнопка **«Файлы Zapret»** на главном экране открывает реально используемую папку движка. В настройках → «Локальные файлы» можно также открыть списки, bin, папку системного hosts и настройки GUI. Сохранённый адрес GeoHide находится в `%LOCALAPPDATA%\ZapretSimpleGui\geohide-address.txt`.

## Содержимое архива

- `ZapretGui-Setup-0.9.12.exe` — установщик с движком и обновлёнными исходниками оболочки.
- `source/` — исходники 0.9.12 и `build.cmd`.
- `source-original/` — исходники исходной версии, сохранённые из прежнего архива.
- `defaults/hosts` — готовый hosts GUI для ручного применения.
- `defaults/list-general.txt` — небольшой штатный список установщика с доменами ChatGPT.
- `defaults/list-general-v3nilla.txt` — полный нормализованный снимок V3nilla для локального импорта.
- `defaults/list-general-user-chatgpt.txt` — четыре домена для добавления в свой пользовательский список; не заменяйте им собственный список целиком, если там есть другие записи.
- `defaults/sources.json` — источники и контрольные суммы снимков.
- `CHANGELOG.md` — текст изменений для GitHub Release.
- `README-0.9.11.txt` — прежнее описание и история оформления.
- `licenses/`, `NOTICE-original.txt`, `ASSETS.txt` — сохранённые лицензии и сведения об исходных компонентах.
- `repack.py` — перепаковка на основе прежнего `ZapretGui-0.9.11/ZapretGui-Setup-0.9.11.exe`; запускать из родительской папки обеих версий. Предыдущий установщик в этот архив повторно не вложен.
- `validation.json` — выполненные проверки и их ограничения.

## Проверка перед публикацией

Установщик распакован обратно и проверен; синтаксис исходников и файлы данных проверены. **Компиляция, установка, отрисовка и работа на Windows в среде подготовки не проверены.** Сначала проверьте обновление на своём ПК: запуск GUI, ALT 11, ChatGPT, обновление и восстановление списков, открытие папок и автозапуск после перезагрузки. Для проверки hosts сохраните копию рабочего файла и проверьте точечное исправление.

Архив подготовлен для загрузки в GitHub вручную; публикация в репозитории из этого чата не выполнялась. После проверки создайте релиз с тегом `v0.9.12`, вставьте текст из CHANGELOG и прикрепите установщик и архив. До завершения проверки удобно сохранить релиз как черновик.
