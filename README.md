# Zapret GUI

Неофициальная графическая оболочка для Zapret на Windows: выбор стратегии, управление подключением, автозапуск, проверка альтернативных вариантов и настройка оформления в одном приложении.

**Версия оболочки: 0.9.11 · Платформа: Windows x64 · Язык интерфейса: русский**

Установщик включает комплект Zapret. Для обычной установки отдельно скачивать и заранее устанавливать Zapret не требуется: его файлы размещаются в папке `zapret` рядом с оболочкой.

Проект использует сторонние компоненты и не является официальным приложением Flowseal, bol-van или Microsoft.

## Возможности

- Запуск и остановка Zapret из интерфейса.
- Выбор стратегии подключения — «альта».
- Проверка альтов и отображение рекомендации по результатам последнего теста.
- Автозапуск выбранной стратегии через службу Windows.
- Диагностика автозапуска и просмотр журналов.
- Работа в системном трее.
- Обновление hosts из источника V3nilla, резервное копирование и восстановление.
- Подготовка hosts для ручной замены, если автоматическая запись не удалась.
- Обновление IP-списка и проверка доступности обновлений Zapret.
- Светлое и тёмное оформление, Liquid Glass и Frutiger Aero.
- Создание, импорт и экспорт пользовательских тем.
- Свои фоновые изображения и значки внутри приложения.
- Плавное переключение тем с возможностью отключить анимации.
- Расширенные параметры в режиме **Advanced mode**.

## Требования

- Windows x64. Целевая система проекта — Windows 11; полная совместимость с другими версиями Windows не подтверждена.
- Права администратора для запуска оболочки и операций со службами, драйвером и системным hosts.
- Доступный компилятор .NET Framework `csc.exe`: установщик использует его для сборки оболочки на компьютере пользователя.
- Доступ в интернет для загрузки обновлений, списков и выполнения сетевых тестов.

Работоспособность конкретной стратегии зависит от провайдера, сети и используемого сервиса. Одинаковый результат на всех подключениях не гарантируется.

## Установка

1. Откройте раздел **Releases** этого репозитория.
2. Скачайте установщик нужной версии. Для версии 0.9.11 файл называется `ZapretGui-Setup-0.9.11.exe`.
3. Если скачан архив, сначала распакуйте его.
4. Запустите установщик и подтвердите запрос прав администратора.
5. После установки откройте Zapret GUI.

Кнопка GitHub **Code → Download ZIP** скачивает содержимое репозитория. Готовый установщик следует искать среди прикреплённых файлов релиза.

### Обновление приложения

1. Завершите оболочку через меню её значка в системном трее.
2. Запустите новый установщик.
3. Выберите прежнюю папку установки.
4. После установки проверьте номер версии в нижней части боковой панели.

При обновлении с 0.9.10 используйте 0.9.11 или более новую версию: в 0.9.10 был конфликт имён переменных, мешавший компиляции оболочки.

## Первый запуск

1. Выберите стратегию в списке «Способ подключения».
2. Нажмите **«Включить Zapret»**.
3. Проверьте нужные сайты и приложения.
4. Если результат не подходит, откройте **«Тестирование»** и запустите проверку альтов.
5. Выберите рекомендованный или другой подходящий вариант и повторите проверку подключения.

Рекомендация отражает результат последнего теста в вашей сети и не гарантирует работу всех сервисов.

### Автозапуск

Чтобы Zapret включался вместе с Windows, выберите подходящую стратегию и нажмите **«Включить автозапуск»**.

Автозапуск относится к фоновой службе Zapret. Окно графической оболочки при загрузке Windows автоматически не открывается — это нормальное поведение.

Для проверки воспользуйтесь действием **«Диагностика автозапуска»** в настройках. Если запуск не удался, сохраните диагностический отчёт.

### Работа в трее

Крестик основного окна скрывает оболочку в системный трей. Чтобы остановить обработку трафика, нажмите **«Остановить»**. Для завершения самой оболочки используйте меню значка в трее.

## Оформление

Раздел **«Темы»** позволяет выбрать готовое оформление или создать своё. Переключатель с солнцем и луной выбирает светлый или тёмный вариант текущей темы.

### Liquid Glass

Оформление с просвечивающими поверхностями, бликами и мягкими контурами. Это собственная отрисовка интерфейса WinForms, а не системный эффект Apple.

### Frutiger Aero

Оформление со стеклянными поверхностями и внутренними рамками в стиле Windows Vista:

- в светлом варианте используются светлые рамки и фон с водой и стеклянными фигурами;
- в тёмном — приглушённые тёмные рамки и статичный фон с офисом и аквариумом;
- тёмный фон встроен как изображение 3840×2160, без воспроизведения видео;
- кнопки «Свернуть» и «Закрыть» на внутренних рамках декоративные: они не нажимаются.

Настоящие системные кнопки находятся в заголовке окна приложения.

### Пользовательские темы

1. Выберите тему, которую хотите взять за основу.
2. Нажмите **«Создать свою»**.
3. Укажите название, настройте цвета светлого и тёмного вариантов, оформление и скругления.
4. При желании выберите собственный фон и значок.
5. Сохраните тему и нажмите **«Применить»**.

Для фона доступны варианты заполнения, вписывания и растягивания, а также настройка непрозрачности. Выбранное изображение сохраняется внутри файла темы.

Пользовательский значок применяется внутри приложения, к окнам и значку в трее. Он не заменяет встроенную иконку EXE и значок ярлыка на рабочем столе.

Темы экспортируются и импортируются в формате `.zttheme`. Встроенную тему можно использовать как основу своей копии; удалить встроенную тему нельзя.

Копия Frutiger Aero наследует разные встроенные фоны для светлого и тёмного вариантов. Выбор собственной картинки заменяет этот режим общим пользовательским фоном.

Старый параметр `night-live="aero-office"` поддерживается для совместимости, но начиная с 0.9.6 выбирает статичное изображение.

### Анимации

Переключатель **«Плавные анимации»** управляет эффектами интерфейса, включая переход между темами. При отключении смена темы выполняется без плавного перехода.

## Работа с hosts

Функция **«Обновить hosts · V3nilla»** загружает файл из стороннего источника и заменяет системный hosts с сохранением резервной копии. При обычной установке приложения hosts не изменяется.

Замена затрагивает содержимое всего файла, поэтому перед применением учитывайте собственные записи, если добавляли их вручную.

Доступны также:

- замена hosts из локального файла;
- восстановление из резервной копии;
- проверка изменений после применения через GUI;
- возврат последнего применённого файла;
- диагностика процессов, использующих hosts;
- скачивание файла для ручной замены.

### Если автоматическая замена не удалась

Причиной могут быть права доступа, использование файла другим процессом или блокировка защитным ПО. Ошибка записи сама по себе не доказывает, что виноват антивирус.

Если файл успешно загружен, приложение может сохранить подготовленный `hosts` в отдельной папке внутри «Загрузок» и открыть её вместе с расположением системного файла:

```text
C:\Windows\System32\drivers\etc
```

Далее можно самостоятельно сохранить копию текущего hosts и перенести подготовленный файл, подтвердив запрос Windows. Имя файла должно быть **`hosts` без расширения**, а не `hosts.txt`.

Приложение не отключает антивирус и не снимает блокировки принудительно. При блокировке проверьте журнал защиты и указанный в нём файл.

## Частые вопросы

### Нужно ли отдельно устанавливать Zapret?

Для готового установщика — нет. Комплект находится внутри установщика и устанавливается вместе с GUI. Он не остаётся только внутри EXE: необходимые рабочие файлы размещаются на диске в папке `zapret`.

### Автозапуск включён, но окно не появилось

Автоматически запускается фоновая служба. Чтобы изменить настройки, откройте оболочку вручную.

### Проверка рекомендует альт, но часть сервисов не работает

Попробуйте другой вариант и повторите тест. Результаты зависят от текущих условий сети и не охватывают все возможные приложения и сценарии.

### Антивирус сообщает об угрозе

Посмотрите точное название обнаружения и путь к файлу. Не считайте любое срабатывание автоматически ложным. Для обращения по проблеме приложите эти сведения и диагностический журнал.

### Установщик пишет «Не удалось подготовить приложение»

Сохраните полный текст ошибки. Если указаны `CS0136` и `CS0029` в `Theme.cs` при установке 0.9.10, установите исправленную версию 0.9.11.

Если отсутствует компилятор .NET Framework, сборка оболочки не сможет завершиться. Запишите сообщение установщика и проверьте наличие необходимых компонентов Windows.

### Как удалить приложение?

Используйте удаление Zapret GUI в параметрах установленных приложений Windows либо штатный деинсталлятор. Если удаление остановилось из-за работающей службы, драйвера или прав доступа, сохраните текст ошибки; не удаляйте вручную случайные системные драйверы.

## Расположение пользовательских данных

Настройки оболочки находятся в:

```text
%LOCALAPPDATA%\ZapretSimpleGui
```

Пользовательские темы и выбор оформления:

```text
%LOCALAPPDATA%\ZapretSimpleGui\themes
```

При наличии журнал последнего запуска сохраняется как `last-launch.log` в папке пользовательских данных.

## Сборка из исходников

Оболочка написана на **C#**, интерфейс — **Windows Forms**, отрисовка — **System.Drawing**.

Для сборки нужны Windows, компилятор .NET Framework и полный набор файлов из папки `source`, включая `app.manifest` и `zapret.ico`.

В PowerShell из корня проекта выполните:

```powershell
cd source
.\build.cmd
```

Скрипт ищет компилятор сначала в:

```text
%SystemRoot%\Microsoft.NET\Framework64\v4.0.30319\csc.exe
```

Затем — в соответствующей папке `Framework`. Результат успешной сборки — `source\ZapretGui.exe`, целевая платформа — x64.

**Сборка оболочки не создаёт комплект Zapret и установщик.** Для работы с включённым движком рядом с собранным EXE нужна папка `zapret` из соответствующей установки.

Скрипт `repack.py` предназначен для перепаковки конкретного предыдущего установщика. Для комплекта 0.9.11 он ожидает файл `ZapretGui-0.9.10/ZapretGui-Setup-0.9.10.exe`. Одних исходников оболочки для его запуска недостаточно.

## Состав проекта

| Путь | Назначение |
| --- | --- |
| `source/` | Актуальные исходники оболочки, ресурсы и скрипт сборки |
| `source-original/` | Исходники оболочки из исходного установщика 0.6 |
| `licenses/` | Лицензионные документы сторонних компонентов |
| `NOTICE-original.txt` | Исходные уведомления и сведения о компонентах |
| `ASSETS.txt` | Происхождение встроенных изображений |
| `validation.json` | Результаты проверки упаковки конкретного установщика |
| `repack.py` | Перепаковка установщика с обновлёнными исходниками |

Некоторые вспомогательные файлы могут находиться только в полном архиве релиза.

## Изменения в 0.9.11

- Исправлен конфликт имён параметра и локальной переменной в отрисовке декоративной кнопки Vista.
- Устранена причина ошибок компилятора `CS0136` и `CS0029`, появившихся в 0.9.10.
- Сохранены светлые рамки для светлого Frutiger Aero и тёмные — для тёмного.
- Предпросмотр учитывает вариант темы.

В предыдущих обновлениях добавлены статичный фон 4K, декоративные кнопки внутренних рамок и улучшения окна выбора тем.

## Статус проверок

Для подготовленного пакета 0.9.11 проверены исправление конфликта имён, лексическая целостность исходников, XML, встроенное изображение, контрольная сумма и обратная распаковка установщика.

Эти проверки **не заменяют компиляцию и запуск на Windows**. Компиляция, установка и отрисовка на Windows не были выполнены в среде подготовки пакета; полноценная матрица совместимости отсутствует.
