# ⚠️ ВАЖНО: ЕСЛИ САЙТЫ ИЛИ ВХОД В META НЕ РАБОТАЮТ — ПРОВЕРЬТЕ DNS!

**Если Meta Quest Developer Hub, Quest Link или сайты Meta не открываются, причиной может быть DNS. Одного запуска Zapret и обновления hosts может быть недостаточно.**

В нашем случае обычный DNS возвращал ошибку «домен не существует» для `auth.meta.com`. После включения **DNS по HTTPS в Windows 11** вход заработал.

**Это исправление подтверждено для конкретного подключения, но не гарантирует устранение любой ошибки входа.**

## Как включить DNS по HTTPS в Windows 11

1. Откройте **Параметры → Сеть и Интернет**.
2. Выберите активное подключение: **Ethernet** для кабеля или **Wi-Fi → свойства подключённой сети**.
3. Найдите **«Назначение DNS-сервера» → «Изменить»**.
4. Сохраните прежние настройки, чтобы при необходимости вернуть их.
5. Выберите **«Вручную»** и включите **IPv4**.
6. Укажите:

| Настройка | Значение |
| --- | --- |
| Предпочитаемый DNS | `1.1.1.1` |
| Альтернативный DNS | `1.0.0.1` |
| DNS по HTTPS для обоих серверов | Включён, автоматический шаблон |
| Возврат к незашифрованному DNS, если доступен | Выключен |

**Меняйте назначение DNS-сервера, а не IP-адрес компьютера. Простая замена DNS без включения HTTPS может не помочь.**

После сохранения выполните в PowerShell или командной строке:

```powershell
ipconfig /flushdns
```

Полностью закройте проблемное приложение и браузер, затем откройте их снова. Оставьте Zapret включённым с вашей рабочей стратегией.

Названия пунктов могут отличаться в зависимости от версии Windows. Для отката верните сохранённые настройки DNS.

# Zapret GUI 0.9.15

Графическая оболочка для управления Zapret в Windows: выбор стратегии, запуск и остановка, обновление списков и работа с hosts. Движок Zapret включён в установщик; оболочка компилируется при установке средствами .NET Framework на Windows.

## Возможности

- Выбор альтов, плавная прокрутка и управление запуском Zapret.
- Темы оформления, в том числе Liquid Glass и Aero, и отключаемые анимации.
- Экран запуска с иконкой и индикатором; при восстановлении из трея не повторяется.
- Встроенный гайд с приглашением при запуске и кнопкой в меню. «Больше не показывать» сохраняется после обычной переустановки для той же учётной записи Windows.
- Обновление списка доменов V3nilla и импорт локального списка.
- Резервные копии и восстановление списков и hosts.
- «Заменить hosts» и «Восстановить hosts» в обычном режиме. Замена применяет встроенный список GUI с сохранённым адресом; совпадающий файл повторно не записывается.
- Advanced mode: GeoHide для ChatGPT/OpenAI, дополнительные операции с hosts, IP-списки, локальные файлы, ручной импорт и техническая диагностика.
- Поиск кандидатов на замену IP в issues и комментариях V3nilla с HTTPS-проверками перед записью.
- Отключаемая автопроверка при запуске GUI.
- Добавление доменов Meta / Quest в пользовательский список и ссылки на страницы скачивания Developer Hub и Quest Link.

## Как работает проверка hosts

Проверяются существующие перенаправления доменов на публичные IPv4-адреса.

**Записи с `0.0.0.0` не изменяются.** Локальные, служебные, IPv6 и конфликтующие записи пропускаются.

Каждый домен проверяется отдельно. Наличие IP в комментарии GitHub само по себе не приводит к замене. Ответы `403` и `429` считаются неоднозначными и не запускают замену текущего адреса.

За проход проверяется до **25 доменов**. Следующая проверка продолжает обход. Перед записью создаётся резервная копия. Переключение Advanced mode не меняет сохранённый выбор автопроверки.

**Эта функция не исправляет системный DNS и не гарантирует работу всех сайтов.** Полное обновление hosts может перезаписать найденные точечные исправления.

## Установка и обновление

1. Сохраните копию рабочей папки Zapret и системного hosts.
2. Остановите Zapret и полностью закройте GUI через трей.
3. Запустите `ZapretGui-Setup-0.9.15.exe` и установите в прежнюю папку.
4. Проверьте номер 0.9.15 в приложении. Выберите рабочую стратегию и запустите Zapret.
5. После изменения списков остановите и снова запустите Zapret.

Для установки и изменения системного hosts нужны права администратора.
